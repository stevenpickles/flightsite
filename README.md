# FlightSite

FlightSite is an open-source, self-hosted ADS-B observability, visualization, analytics,
history, and interesting-aircraft notification platform for homelab users.

It answers the question:

> What is my receiver seeing, what has it seen historically, how unusual is what I am
> seeing now, and is anything particularly interesting happening?

**Status: pre-release — Phase 0 (planning).** See [`docs/ROADMAP.md`](docs/ROADMAP.md)
and [`planning/roadmap.yaml`](planning/roadmap.yaml) for the development plan.
